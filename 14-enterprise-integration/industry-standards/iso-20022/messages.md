# ISO 20022 Core Message Catalog

## 1. Domain Breakdown

| Domain | Description | Key Messages |
| :--- | :--- | :--- |
| **pacs** | Payments Clearing and Settlement | `pacs.008` (Credit Transfer), `pacs.009` (Financial Institution Transfer), `pacs.002` (Status) |
| **pain** | Payments Initiation | `pain.001` (Customer Credit Transfer), `pain.002` (Status Report), `pain.008` (Direct Debit) |
| **camt** | Cash Management | `camt.053` (Bank Statement), `camt.054` (Debit/Credit Notification), `camt.052` (Report) |
| **remt** | Remittance Advice | `remt.001` (Electronic Remittance Advice) |
| **seev** | Securities Events | Corporate actions and proxy voting |
