# HL7 v2 Core Message Types

## 1. Clinical Message Catalog

| Trigger Event | Purpose | Clinical Scenario |
| :--- | :--- | :--- |
| **ADT^A01** | Patient Admit / Visit Notification | Patient admitted to hospital bed |
| **ADT^A08** | Update Patient Information | Patient address or demographic updated |
| **ORM^O01** | General Order Message | Physician orders lab work or radiology exam |
| **ORU^R01** | Unsolicited Observation Result | Lab analyzer returns blood test results |
| **SIU^S12** | Schedule Information Notification | Outpatient clinic appointment booked |
| **MDM^T02** | Medical Document Management | Physician signs clinical consultation note |
