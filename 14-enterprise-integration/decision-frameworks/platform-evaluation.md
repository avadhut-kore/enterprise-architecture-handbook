# Integration Platform Evaluation and Scoring Framework

## 1. RFP Evaluation Criteria Matrix
When evaluating commercial iPaaS (MuleSoft, Boomi, Workato), API Gateways (Kong, Apigee), or Event Platforms (Confluent Kafka):
- **Protocol & Connector Coverage (Weight: 25%)**: Breadth of certified enterprise adapters.
- **Runtime Performance & Latency (Weight: 20%)**: p99 overhead under 5,000 concurrent connections.
- **Security & Compliance (Weight: 20%)**: FIPS 140-2, PCI-DSS Level 1, SOC 2 Type II, HIPAA compliance.
- **Developer Experience & CI/CD (Weight: 15%)**: Declarative configuration (YAML/Terraform), GitOps compatibility.
- **Total Cost of Ownership (Weight: 20%)**: Core licensing, throughput-based overage fees, infrastructure footprint.
