# AI-Native Architecture Patterns (`ai-native/`)

## Executive Summary

An **AI-Native Architecture** is not a traditional software application with an AI feature retrofitted onto an existing API. It is an architecture designed from the ground up to operate in an environment where **non-deterministic probabilistic models are central execution components**.
