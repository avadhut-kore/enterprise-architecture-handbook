# Edge Computing & Distributed Runtimes (`edge/`)

## Executive Summary

Edge architecture shifts computation, data caching, and AI inference from centralized cloud datacenters directly to the network edge (Points of Presence, CDN PoPs, regional edge gateways, and IoT devices).
