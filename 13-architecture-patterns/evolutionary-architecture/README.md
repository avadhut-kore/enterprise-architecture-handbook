# Evolutionary Architecture & Fitness Functions (`evolutionary-architecture/`)

## Executive Summary

Systems that cannot change gracefully in response to technological and business evolution inevitably decay into legacy liabilities.

**Evolutionary Architecture** designs systems for guided, incremental change across multiple dimensions using automated **Architectural Fitness Functions**.
