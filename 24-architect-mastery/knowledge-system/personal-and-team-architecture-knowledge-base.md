# Personal and Team Architecture Knowledge Base

Great architects possess superior mental models because they maintain systematic, persistent external memory systems ("Second Brains").

## 1. The Architect's Knowledge Stack

```
┌─────────────────────────────────────────────────────────────┐
│ 1. DAILY CAPTURE & NOTES (SCRATCHPAD)                       │
│ Quick capture of incident symptoms, whiteboard photos,     │
│ meeting notes, and emergent design questions.               │
├─────────────────────────────────────────────────────────────┤
│ 2. CURATED MENTAL MODELS & PATTERNS (ATOMIC NOTES)          │
│ Synthesized patterns: Outbox pattern, CRDT mechanics,       │
│ consensus algorithms, PACELC trade-offs.                    │
├─────────────────────────────────────────────────────────────┤
│ 3. ENTERPRISE REPOSITORIES & LIVING HANDBOOKS               │
│ Git-backed Markdown handbooks (e.g., this handbook!), ADRs, │
│ C4 diagrams, and architectural RFCs.                        │
├─────────────────────────────────────────────────────────────┤
│ 4. WAR STORIES & POST-MORTEM ARCHIVE                        │
│ Systematic analysis of past failures, root causes, and      │
│ preventive fitness functions.                               │
└─────────────────────────────────────────────────────────────┘
```

## 2. Knowledge Principles for Architects
- **Plain Text & Git**: Never lock architectural knowledge in proprietary SaaS silos. Git-versioned Markdown ensures portability, full-text grep search, and longevity over decades.
- **Zero Broken Links**: Maintain structural hypertext linking across all architectural decisions.
