# Multi-Agent Systems Architecture (`multi-agent/`)

## Executive Summary

When a single autonomous agent is overwhelmed by too many tools or conflicting system instructions, cognitive load degrades performance. 

**Multi-Agent Systems** decompose monolithic tasks across specialized agent personas (e.g., Researcher, Coder, Critic, Supervisor), coordinating execution via structured choreography or orchestration.
