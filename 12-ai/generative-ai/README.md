# Generative AI Architecture (`generative-ai/`)

## Executive Summary

Generative Artificial Intelligence represents a paradigm shift from discriminative classification to probabilistic content synthesis across text, code, audio, images, and structured data.

This module details the architectural principles governing foundation models, multimodal ingestion/synthesis, deterministic structured output generation, and function calling primitives.
