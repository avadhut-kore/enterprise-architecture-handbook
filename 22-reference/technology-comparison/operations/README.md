# Operational & SRE Technology Comparison Matrices (`technology-comparison/operations/`)

## Executive Summary

This directory provides multidimensional comparative matrices evaluating operational architectures, deployment strategies, and monitoring models.

---

## Matrices Index
- **`active-active-vs-active-passive.md`**: Synchronous active-active vs Warm standby disaster recovery.
- **`canary-vs-blue-green.md`**: Progressive canary rollouts vs Atomic blue-green deployments.
- **`centralized-vs-team-owned-ops.md`**: Platform Engineering Golden Paths vs Decentralized team operations.
- **`threshold-vs-burn-rate-alerting.md`**: CPU/Memory static thresholds vs Multi-window SLO burn rates.
- **`gitops-vs-ci-cd-push.md`**: Pull-based GitOps (ArgoCD) vs Push-based pipeline scripts.
- **`restore-testing-vs-backup-verification.md`**: Snapshot integrity check vs Ephemeral automated restore drills.
