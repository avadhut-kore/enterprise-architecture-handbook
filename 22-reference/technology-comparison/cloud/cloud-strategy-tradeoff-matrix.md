# Technology Comparison: Cloud Strategy Trade-Off Matrix

## Executive Summary
This reference matrix evaluates the architectural trade-offs between single cloud vs multi cloud.

---

## Architectural Comparison Matrix

| Dimension | Single-Cloud Specialization | Multi-Cloud Diversification |
| :--- | :--- | :--- |
| **Operational Complexity** | Low (Unified tooling, IAM, networking) | Exponential (Fragmented toolchains, disparate IAM) |
| **Lock-in Risk** | Higher (Dependent on 1 vendor) | Lower (Architectural portability) |
| **Negotiating Leverage** | High (Consolidated enterprise volume discount)| Low (Fragmented spend across multiple vendors) |
| **Latency Overhead** | Sub-millisecond intra-region | 15–40ms WAN cross-cloud RTT |
| **Security Posture** | Cohesive governance via single landing zone | Fractured security boundaries and audit complexity |
