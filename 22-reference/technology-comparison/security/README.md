# Security Technology Comparison Matrices (`technology-comparison/security/`)

## Executive Summary

This directory provides multidimensional comparative decision matrices evaluating competing security technologies, identity protocols, and cryptographic strategies.

---

## Matrices Index
- **`jwt-vs-opaque-tokens.md`**: Stateless JSON Web Tokens vs Stateful Reference Tokens.
- **`rbac-vs-abac-vs-rebac.md`**: Role-Based vs Attribute-Based vs Relationship-Based authorization.
- **`oauth2-vs-api-keys.md`**: Delegated OAuth tokens vs Static API keys.
- **`oidc-vs-saml.md`**: OpenID Connect JSON tokens vs SAML 2.0 XML assertions.
- **`mtls-vs-token-auth.md`**: Transport-layer mutual TLS vs Application-layer bearer tokens.
- **`kms-vs-hsm.md`**: Cloud KMS multi-tenant keys vs Dedicated Cloud HSM appliances.
- **`centralized-vault-vs-cloud-secrets.md`**: HashiCorp Vault vs Native Cloud Secrets Manager.
- **`sast-vs-dast-vs-sca.md`**: Static vs Dynamic vs Software Composition Analysis tools.
