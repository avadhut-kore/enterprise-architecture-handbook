# Consumer-Driven Contract Testing

In distributed microservices, end-to-end integration environments are slow, fragile, expensive, and difficult to maintain.

**Contract Testing** verifies that microservices can communicate correctly by testing requests and responses against shared, machine-readable contracts (Pact), completely without deploying integrated environments.
