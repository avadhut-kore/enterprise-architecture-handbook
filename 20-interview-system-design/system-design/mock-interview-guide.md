# Peer Mock Interview Execution Guide

## 1. Mock Session Structure (60 Minutes Total)

```
00:00 - 05:00: Interviewer sets prompt and problem background.
05:00 - 50:00: Candidate executes 45-minute System Design Interview.
50:00 - 60:00: Structured feedback session using the evaluation rubric.
```
