# Enterprise Architecture Diagram Templates Reference

This guide describes how to select, copy, and customize the raw diagram templates in this directory.

## File Extension Conventions
* `.mmd`: Raw Mermaid syntax files. Copy directly into GitHub Markdown using triple backticks with `mermaid`.
* `.puml`: Raw PlantUML syntax files. Render using PlantUML CLI or IntelliJ/VS Code PlantUML extensions.

## Embedding Example in Markdown
```markdown
```mermaid
<!-- Paste content of .mmd file here -->
```
```
