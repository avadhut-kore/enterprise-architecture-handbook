# Enterprise Integration Architecture Diagrams & EIP Patterns

This directory provides standardized architectural patterns and visual models for enterprise application integration (EAI), messaging topologies, API gateways, and event-driven fabrics.

## Pattern Catalog
- [Point-to-Point Integration](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/point-to-point.md): Tightly coupled direct system linkages and risks.
- [Hub-and-Spoke Integration](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/hub-and-spoke.md): Centralized integration broker model.
- [Enterprise Service Bus (ESB)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/esb.md): Legacy mediation, transformation, and protocol bridging.
- [Modern API Gateway Integration](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/api-gateway.md): Lightweight, cloud-native API management.
- [Event Mesh Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/event-mesh.md): Distributed multi-cloud event routing fabric.
- [Event-Driven Architecture (EDA)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/eda.md): Reactive event-driven integration paradigms.
- [RPC vs Events Trade-off Model](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/rpc-vs-events.md): Synchronous request-response vs asynchronous messaging.
- [Integration Topology Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/template.md): Reusable integration architecture template.
- [Integration Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/integration/checklists.md): Enterprise integration audit checklist.
