# DevOps, GitOps & Continuous Delivery Architecture Diagrams

This directory provides standardized architectural patterns and visual models for automated CI/CD pipelines, GitOps reconciliation, progressive delivery (Canary / Blue-Green), and end-to-end observability architectures.

## Pattern Catalog
- [GitOps Continuous Delivery Flow](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/gitops-pipeline.md): Declarative reconciliation with ArgoCD and Flux.
- [CI/CD Pipeline Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/ci-cd-flow.md): Build, test, security gates, and artifact publishing.
- [Blue-Green Deployment Topology](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/blue-green.md): Instant zero-downtime routing cutover.
- [Canary Deployment Topology](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/canary.md): Incremental traffic shifting and automated metric analysis.
- [Observability Pipeline Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/observability-pipeline.md): OpenTelemetry collector, metrics, logs, and traces.
- [DevOps Architecture Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/template.md): Reusable deployment pipeline template.
- [DevOps Architecture Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/devops/checklists.md): Continuous delivery audit checklist.
