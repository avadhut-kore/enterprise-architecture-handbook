# C4 Model Diagram Review Checklist

- [ ] Does the System Context (L1) diagram show user personas and external enterprise systems?
- [ ] Does the Container (L2) diagram show all deployable units (SPAs, mobile apps, microservices, databases)?
- [ ] Does the Component (L3) diagram illustrate internal modules without degenerating into low-level code?
- [ ] Are technologies explicitly labeled in brackets (e.g., `[Container: Java, Spring Boot]`)?
- [ ] Are protocols and wire formats explicitly specified on all relationship lines (e.g., `JSON/HTTPS`, `gRPC`)?
