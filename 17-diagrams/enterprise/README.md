# Enterprise Architecture (EA) Maps & Strategic Topologies

This directory provides standardized visual models for Enterprise Architecture, Business Capability Maps, Application Portfolio Management (TIME model), Integration Landscapes, and Technology Radars.

## Pattern Catalog
- [Business Capability Map](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/business-capability-map.md): Strategic hierarchical business capability decomposition.
- [Application Portfolio Matrix (TIME)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/application-portfolio.md): Gartner TIME rationalization framework.
- [Enterprise Integration Landscape](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/integration-landscape.md): Macro-level enterprise system connectivity topology.
- [Enterprise Technology Radar](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/technology-radar.md): ThoughtWorks style Adopt, Trial, Assess, Hold rings.
- [Enterprise Architecture Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/template.md): Reusable enterprise architecture diagram template.
- [Enterprise Architecture Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/enterprise/checklists.md): Strategic EA review checklist.
