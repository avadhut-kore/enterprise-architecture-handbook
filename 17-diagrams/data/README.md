# Enterprise Data Architecture Diagrams & Storage Patterns

This directory provides standardized architectural patterns and visual models for enterprise data architecture, Data Mesh topologies, distributed database clustering, sharding, and replication.

## Pattern Catalog
- [Data Mesh Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/data-mesh.md): Decentralized domain-oriented data ownership & data products.
- [Data Fabric Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/data-fabric.md): Automated metadata-driven active integration fabric.
- [Database Clustering Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/database-clustering.md): High-availability clusters, quorum, and failover.
- [Database Sharding Topology](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/sharding.md): Horizontal database partitioning and routing keys.
- [Database Replication Strategies](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/replication.md): Synchronous, asynchronous, and multi-region replication.
- [Data Architecture Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/template.md): Reusable data topology template.
- [Data Architecture Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/data/checklists.md): Data architecture review checklist.
