# System Architecture & Solution Design Artifacts

This directory contains standardized architectural blueprints, High-Level Designs (HLD), Low-Level Designs (LLD), visual Architecture Decision Records (ADRs), and architectural trade-off frameworks.

## Artifact Catalog
- [System Architecture Document (SAD)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/system-architecture-document.md): Master enterprise blueprint framework.
- [High-Level Design (HLD)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/high-level-design.md): System boundary, capability mapping, and component topology.
- [Low-Level Design (LLD)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/low-level-design.md): Detailed class models, sequence execution, and database schemas.
- [ADRs Visualized](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/adrs-visualized.md): Architectural decision models and consequences.
- [Trade-off Matrix](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/tradeoff-matrix.md): Visualizing non-functional requirements (NFR) tradeoffs.
- [Architecture Blueprint Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/template.md): Standard starting template.
- [Architecture Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/architecture/checklists.md): ARB submission audit list.
