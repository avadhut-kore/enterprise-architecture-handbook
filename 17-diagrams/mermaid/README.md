# Mermaid Diagramming Reference & Syntax Library

Mermaid is the native Markdown-embedded diagramming language supported across GitHub, GitLab, Azure DevOps, Notion, and modern documentation frameworks.

This directory provides comprehensive syntax guides, styling rules, best practices, and copy-pasteable architectural patterns for every Mermaid diagram type used by Enterprise and Solution Architects.

- [Sequence Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/mermaid/sequence.md): Participants, actors, loops, alt/else, and autonumbering.
