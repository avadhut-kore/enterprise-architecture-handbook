# PlantUML Architecture Diagram Checklist

- [ ] Does the diagram compile without syntax errors via the PlantUML CLI/JAR?
- [ ] Are modern skinparams included to eliminate outdated yellow/red styling?
- [ ] Are autonumbering directives enabled on sequence diagrams?
- [ ] Are lifelines explicitly activated and deactivated?
- [ ] Are wire protocols explicitly noted on interaction arrows?
- [ ] Are external third-party systems cleanly segregated in external system boundaries?
