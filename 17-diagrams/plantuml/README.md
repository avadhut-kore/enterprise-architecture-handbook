# PlantUML Reference & Architecture Modeling Library

PlantUML is a mature, open-source diagramming-as-code standard supporting UML 2.0 specifications, rich deployment topologies, component interactions, and C4-PlantUML extensions.

## PlantUML Catalog
- [Syntax Guide & Cheatsheet](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/syntax-guide.md): Universal skinparams, nodes, packages, and links.
- [Component Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/component.md): Subsystems, ports, interfaces, and dependencies.
- [Sequence Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/sequence.md): Participants, lifelines, activation boxes, and alt/opt blocks.
- [Deployment Topologies](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/deployment.md): Nodes, devices, execution environments, and cloud infrastructure.
- [Activity Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/activity.md): Business workflows, decision forks, and swimlanes.
- [State Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/state.md): State machines, composite states, and concurrent regions.
- [Class Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/class.md): Object modeling, class members, and design patterns.
- [Use Case Diagrams](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/usecase.md): Actors, system boundaries, include, and extend relations.
- [C4-PlantUML Library Guide](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/c4-plantuml.md): Production C4 modeling with C4-PlantUML standard library.
- [Styling & Skinparams Guide](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/styling-guide.md): Theming, fonts, monochrome, and color overrides.
- [PlantUML Starter Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/template.md): Production-ready starting template.
- [PlantUML Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/plantuml/checklists.md): Verification checklist for PlantUML diagrams.
