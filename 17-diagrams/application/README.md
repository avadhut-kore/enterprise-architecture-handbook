# Application Architecture Diagrams & Structural Patterns

This directory provides standardized architectural patterns and visual models for application software structure, domain layering, Hexagonal/Clean Architecture, and microservices decomposition.

## Pattern Catalog
- [Layered Architecture (N-Tier)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/layered.md): Classic presentation, business, persistence layering.
- [Hexagonal Architecture (Ports & Adapters)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/hexagonal.md): Decoupling business logic from external I/O.
- [Clean Architecture (Onion Pattern)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/clean.md): Strict dependency rule pointing inward.
- [Microservices Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/microservices.md): Decentralized bounded contexts and distributed state.
- [Modular Monolith Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/modular-monolith.md): In-process encapsulation with domain modules.
- [Event-Driven Application Architecture](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/event-driven.md): Asynchronous choreographies and event brokers.
- [CQRS & Event Sourcing (CQRS/ES)](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/cqrs-es.md): Read/Write segregation and immutable event streams.
- [Application Architecture Template](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/template.md): Boilerplate application modeling template.
- [Application Architecture Review Checklist](file:///d:/company/products/enterprise-architecture-handbook/17-diagrams/application/checklists.md): Application structure review checklist.
