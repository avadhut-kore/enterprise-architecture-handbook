# Root Cause Analysis (RCA) Techniques

## Executive Summary

In complex distributed systems, incidents rarely have a single root cause. They arise from a confluence of contributing factors.
1. **5 Whys Analysis**: Drilling past symptoms to discover architectural deficiencies.
2. **Fishbone (Ishikawa) Diagrams**: Categorizing contributing factors across Infrastructure, Code, Process, Telemetry, and Human factors.
