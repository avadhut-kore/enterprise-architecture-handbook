# ADR-0010: Multi-Region Headless Synthetic Probing for Critical Paths

* **Status**: Accepted
* **Date**: 2026-07-15
* **Deciders**: VP of Digital Experience, SRE Practice Lead, Lead Architect
* **Technical Story**: [ARCH-OBS-010] Active Probing Strategy

---

## Context and Problem Statement
Passive telemetry (metrics and logs generated by incoming user requests) is blind during low-traffic periods (e.g., 3:00 AM on Sunday). If authentication or payment gateways fail during quiet windows, passive alerts will not trigger because zero users are failing. Furthermore, passive telemetry fails to isolate regional DNS or CDN transit failures.

## Decision Drivers
* 24/7/365 active verification of critical business user journeys (Authentication, Search, Checkout).
* Detection of regional edge routing outages independent of user volume.
* Verification of frontend rendering performance (Core Web Vitals) alongside backend APIs.

## Considered Options
1. **Option 1**: Passive monitoring only (Rely on real user traffic).
2. **Option 2**: Simple HTTP GET ping probes (`/healthz` checks).
3. **Option 3**: **Multi-Region Headless Browser Synthetic Journeys (Playwright / Puppeteer)**.

## Decision Outcome
**Chosen Option**: **Option 3: Multi-Region Headless Synthetic Journeys**.

### Positive Consequences
* **Full Journey Coverage**: Headless browsers execute realistic multi-step customer flows (login, add to cart, submit test payment).
* **Multi-Cloud Geographies**: Probes run every 2 minutes from 4 distinct global cloud regions, immediately flagging localized CDN/DNS failures.
* **Off-Peak Protection**: Outages occurring during the night are detected and mitigated hours before peak morning traffic arrives.

### Negative Consequences
* Synthetic test accounts and sandbox credit card configurations must be maintained to prevent false positives.
