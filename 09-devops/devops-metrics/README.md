# DevOps Metrics & Engineering Measurement

If you cannot measure delivery, you cannot improve it. However, measuring the wrong metrics incentivizes pathological developer behavior.

## Contents

- [DORA Metrics Deep Dive](./dora-metrics-deep-dive.md) — The 4 DORA metrics, measurement methodologies, avoiding gaming traps, and Space/Flow frameworks.

## Core Warning
**Goodhart's Law**: *"When a measure becomes a target, it ceases to be a good measure."* Never evaluate individual developers based on commit counts, lines of code, or PR volume.
