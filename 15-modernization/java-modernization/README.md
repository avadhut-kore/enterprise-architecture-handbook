# Java Enterprise Modernization Playbook

## 1. Overview
Modernizing enterprise Java platforms (Java EE, WebLogic, WebSphere, JBoss, Spring 3/4) to modern cloud-native standards (Java 17/21, Spring Boot 3, Quarkus, Virtual Threads) is essential for cloud velocity and cost reduction.

## 2. Directory Structure
- [java-ee-to-spring-boot.md](java-ee-to-spring-boot.md): EJB, JMS, and Servlet migration to Spring Boot.
- [weblogic-websphere-to-containers.md](weblogic-websphere-to-containers.md): Decommissioning heavyweight app servers.
- [monolithic-ear-war-decomposition.md](monolithic-ear-war-decomposition.md): Splitting monolithic archives into micro-jars.
- [spring-framework-legacy-upgrade.md](spring-framework-legacy-upgrade.md): Upgrading legacy Spring 3/4 to Spring Boot 3.
- [orm-hibernate-modernization.md](orm-hibernate-modernization.md): Modernizing Hibernate mapping and native queries.
- [blocking-io-to-reactive-virtual-threads.md](blocking-io-to-reactive-virtual-threads.md): Leveraging Java 21 Project Loom virtual threads.
- [java-build-and-ci-modernization.md](java-build-and-ci-modernization.md): Ant/Maven legacy migration to modern Gradle/Maven & CI.
