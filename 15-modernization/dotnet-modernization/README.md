# .NET Enterprise Modernization Playbook

## 1. Overview
Modernizing legacy Microsoft .NET systems (.NET Framework 3.5/4.x, WCF, ASP.NET WebForms, Windows Services, ASMX) to modern cross-platform .NET (8/9) running on Linux containers enables 80% infrastructure cost reduction and massive performance gains.

## 2. Directory Structure
- [dotnet-framework-to-dotnet-core.md](dotnet-framework-to-dotnet-core.md): .NET Framework 4.x to .NET 8/9 migration playbook.
- [wcf-to-grpc-and-webapi.md](wcf-to-grpc-and-webapi.md): Modernizing SOAP-based WCF services to gRPC and REST Web APIs.
- [aspx-webforms-to-modern-web.md](aspx-webforms-to-modern-web.md): Migrating ASP.NET WebForms to ASP.NET Core / Blazor.
- [iis-to-linux-containers.md](iis-to-linux-containers.md): Decoupling from Windows IIS to Linux containers on Kubernetes.
- [entity-framework-upgrade.md](entity-framework-upgrade.md): EF 6.x to EF Core migration and breaking query patterns.
- [windows-services-to-worker-services.md](windows-services-to-worker-services.md): Migrating background Windows Services to .NET Worker Services.
- [dotnet-build-and-packaging.md](dotnet-build-and-packaging.md): Modernizing MSBuild, NuGet packaging, and cross-platform CI.
