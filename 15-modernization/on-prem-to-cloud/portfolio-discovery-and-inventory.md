# Automated Portfolio Discovery & Dependency Mapping

## 1. Discovery Tooling
Manual spreadsheets are obsolete before they are completed. Deploy automated discovery appliances (AWS Application Discovery Service, Azure Migrate Appliance, Device42, Flexera) to:
- Intercept network packet flows to discover hidden upstream and downstream TCP/UDP ports.
- Inventory installed software packages, database versions, and CPU/Memory utilization percentiles.
- Identify "affinity groups"—clusters of servers that share heavy intra-application latency and must migrate together in the same wave.
