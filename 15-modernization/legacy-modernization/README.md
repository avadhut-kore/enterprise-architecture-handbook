# Legacy Systems Modernization Architecture Library

## 1. Overview
Legacy systems (mainframes, AS/400, COBOL, client-server applications, monolithic batch jobs) are the durable backbones of global banking, insurance, airlines, and government agencies. 

This directory delivers practical blueprints for modernizing legacy platforms without catastrophic big-bang replacements.

## 2. Directory Structure
- [mainframe-modernization-strategies.md](mainframe-modernization-strategies.md): Rehost, refactor, wrap, or replace IBM z/OS mainframes.
- [cobol-and-copybook-modernization.md](cobol-and-copybook-modernization.md): Automated translation, copybook parsing, and microservices.
- [batch-processing-to-event-streaming.md](batch-processing-to-event-streaming.md): Decomposing overnight batch windows into real-time streams.
- [file-transfer-and-ftp-modernization.md](file-transfer-and-ftp-modernization.md): Modernizing flat-file and SFTP interfaces to REST/Kafka.
- [soap-and-esb-modernization.md](soap-and-esb-modernization.md): Decommissioning monolithic ESBs into lightweight integration meshes.
- [terminal-and-green-screen-modernization.md](terminal-and-green-screen-modernization.md): Screen scraping mitigation and API encapsulation.
- [legacy-operating-systems-and-vms.md](legacy-operating-systems-and-vms.md): Modernizing Windows Server 2008/2012, AIX, Solaris, RHEL 5/6.
- [client-server-app-modernization.md](client-server-app-modernization.md): Visual Basic, Delphi, PowerBuilder to modern web/cloud.
- [legacy-retirement-and-data-archival.md](legacy-retirement-and-data-archival.md): Cold data archiving, legal holds, and system shutdown.
