# Modernization Reference Architectures

## 1. Overview
This directory contains 10 production-grade reference architecture blueprints illustrating end-to-end modernization pathways for common enterprise legacy topologies.

## 2. Reference Blueprints Catalog
1. [01-monolith-to-modular-monolith.md](01-monolith-to-modular-monolith.md): Monolith to Modular Monolith with bounded contexts.
2. [02-monolith-to-microservices-strangler.md](02-monolith-to-microservices-strangler.md): Monolith to Microservices via Strangler Fig and API Gateway.
3. [03-shared-db-to-domain-databases.md](03-shared-db-to-domain-databases.md): Shared database to domain-owned isolated databases.
4. [04-on-prem-to-cloud-landing-zone.md](04-on-prem-to-cloud-landing-zone.md): On-premises datacenter migration to enterprise cloud landing zone.
5. [05-legacy-batch-to-event-driven.md](05-legacy-batch-to-event-driven.md): Overnight batch window to real-time event streaming.
6. [06-legacy-soap-to-api-platform.md](06-legacy-soap-to-api-platform.md): Legacy SOAP/XML services to modern REST/GraphQL API platform.
7. [07-mainframe-to-modern-app-layer.md](07-mainframe-to-modern-app-layer.md): Mainframe core to cloud event-driven caching layer.
8. [08-legacy-reporting-to-modern-data.md](08-legacy-reporting-to-modern-data.md): Legacy operational reporting to Lakehouse / Data Mesh.
9. [09-hybrid-legacy-plus-cloud.md](09-hybrid-legacy-plus-cloud.md): Multi-year hybrid coexistence architecture.
10. [10-enterprise-modernization-platform.md](10-enterprise-modernization-platform.md): Scalable enterprise modernization platform and factory.
