# Specialized Domain Architect Roles

In large enterprises, specialized domain architects own cross-cutting architectural disciplines across all business units.

---

## 1. Data Architect
* **Mandate**: Enterprise information architecture, data governance, MDM, data products, and analytics.
* **Key Deliverables**: Enterprise conceptual/logical data models, data mesh domain boundaries, data retention policies, master data catalogs.
* **Cross-Link**: See [06-data](../../06-data/README.md) for deep technical implementation patterns.

## 2. Application Architect
* **Mandate**: Software engineering standards, framework lifecycles, microservice/modular monolith patterns, and application health.
* **Key Deliverables**: Golden path application templates, dependency policies, component modularity standards, API design standards.
* **Cross-Link**: See [01-architecture](../../01-architecture/README.md) and [03-backend](../../03-backend/README.md).

## 3. Security Architect
* **Mandate**: Enterprise Zero Trust architecture, identity and access management (IAM), cryptography, threat modeling, and compliance.
* **Key Deliverables**: Enterprise security architecture blueprints, IAM federation specs, STRIDE threat models, security review gates.
* **Cross-Link**: See [10-security](../../10-security/README.md).

## 4. Cloud & Infrastructure Architect
* **Mandate**: Global cloud landing zones, hybrid networking, compute platforms (Kubernetes), disaster recovery, and FinOps cost governance.
* **Key Deliverables**: Multi-account cloud topology, Infrastructure as Code (Terraform) modules, cloud networking blueprints.
* **Cross-Link**: See [08-cloud](../../08-cloud/README.md).
