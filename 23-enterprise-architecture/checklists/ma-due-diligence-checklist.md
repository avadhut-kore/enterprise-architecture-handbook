# M&A Technology Due Diligence Checklist

- [ ] Codebase scanned for viral open source licenses (GPL/AGPL).
- [ ] Historical security incidents, CVE vulnerabilities, and pentest reports audited.
- [ ] Systems running on end-of-life (EOL) operating systems or databases identified.
- [ ] Cloud vendor contracts and minimum-spend commitments audited for financial liability.
- [ ] Key architectural personnel interviewed; single-point-of-failure talent risks mapped.
