# 18. Reference Architectures: Master Catalog

Welcome to the **Master Reference Architecture Catalog** of the Enterprise Architecture Handbook. This repository hosts end-to-end production reference blueprints across technology domains, industry verticals, and architectural disciplines.

## Master Reference Architecture Collections

### 1. Global & Cross-Cutting Reference Architectures (This Domain)
The subdirectories within this domain provide canonical reference architectures spanning technical disciplines and industry verticals:
* [`system-design/`](./system-design/) — Planetary-scale distributed systems, high-throughput engines, and core infra patterns (31 blueprints).
* [`full-stack/`](./full-stack/) — Complete end-to-end full-stack architectures combining frontend, backend, data, and cloud (12 blueprints).
* [`cloud/`](./cloud/) — Multi-region, hybrid, and cloud-native topologies on AWS, Azure, and GCP (11 blueprints).
* [`data/`](./data/) — Data lakehouses, streaming analytics meshes, and distributed databases (11 blueprints).
* [`integration/`](./integration/) — Enterprise API gateways, event hubs, and async messaging architectures (13 blueprints).
* [`financial/`](./financial/) — Real-time payment rails, clearing houses, and high-frequency ledgers (11 blueprints).

* [`ai-modern/`](./ai-modern/) — Enterprise RAG, agent swarms, vector retrieval, and LLM serving fabrics (21 blueprints).
