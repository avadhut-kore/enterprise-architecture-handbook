# Security Architecture Checklists & Review Gates (`10-security/checklists/`)

## Executive Summary

Enterprise security reviews cannot rely on informal tribal memory. This directory provides direct access to the enterprise architecture review gates, compliance checklists, and security verification frameworks used by Architecture Review Boards (ARB) across Fortune 500 organizations.

---

## Master Security Checklists Index

All operational checklists have been centralized within the handbook's architecture tools repository for seamless cross-domain assessment:

* **[Master Security Checklists Catalog](../../21-architecture-tools/checklists/security/README.md)** — Centralized security checklist registry.
* **[Security Architecture Review Checklist](../../21-architecture-tools/checklists/security/security-architecture-review.md)** — Mandatory ARB gate checklist covering threat modeling, crypto, IAM, and blast radius.
* **[Threat Model Review Checklist](../../21-architecture-tools/checklists/security/threat-model-review.md)** — DFD boundary validation, STRIDE coverage, and mitigation tracking.
* **[Identity & Access Review Checklist](../../21-architecture-tools/checklists/security/identity-review.md)** — MFA/FIDO2, SCIM lifecycles, session timeouts, and token rotation.
* **[API Security Review Checklist](../../21-architecture-tools/checklists/security/api-security-review.md)** — Rate limiting, schema validation, mTLS, and OWASP API Top 10 defenses.
* **[Application Security Review Checklist](../../21-architecture-tools/checklists/security/application-security-review.md)** — OWASP Top 10 mitigations, SSRF guards, and secure coding practices.
* **[Data Security Review Checklist](../../21-architecture-tools/checklists/security/data-security-review.md)** — Envelope encryption, KMS key rotation, and classification controls.
* **[Cloud Security Review Checklist](../../21-architecture-tools/checklists/security/cloud-security-review.md)** — CSPM enforcement, IMDSv2, VPC egress filtering, and IAM boundaries.
* **[Kubernetes Security Review Checklist](../../21-architecture-tools/checklists/security/kubernetes-security-review.md)** — Pod Security Standards `restricted`, distroless images, and network policies.
* **[DevSecOps Review Checklist](../../21-architecture-tools/checklists/security/devsecops-review.md)** — CI/CD automated gates, artifact signing, and policy enforcement.
* **[Compliance Architecture Review Checklist](../../21-architecture-tools/checklists/security/compliance-architecture-review.md)** — GDPR, PCI-DSS 4.0, HIPAA, and SOC 2 attestation verification.
