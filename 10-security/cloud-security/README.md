# Cloud Security Architecture (`cloud-security/`)

## Executive Summary

Cloud security operates under the Shared Responsibility Model. This directory establishes the architectural governance required to enforce least privilege, continuous posture management, and blast radius containment across AWS, Azure, and GCP.
