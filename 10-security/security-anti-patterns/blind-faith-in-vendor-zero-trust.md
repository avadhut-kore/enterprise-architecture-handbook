# Security Anti-Pattern: Blind Faith in Vendor Zero Trust Tools

## 1. Description & Context
Blind Faith in Vendor Zero Trust Tools introduces severe systemic risk, violating the core tenets of defense-in-depth and least privilege.

## 2. Symptoms & Consequences
- Buying a product vs designing architecture

## 3. Root Cause
- Architectural shortcuts, unmanaged technical debt, or lack of automated preventative guardrails.

## 4. Architectural Refactoring
- **Remediation**: Holistic Zero Trust across identity, data, network
