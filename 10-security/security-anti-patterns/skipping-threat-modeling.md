# Security Anti-Pattern: Skipping Threat Modeling

## 1. Description & Context
Skipping Threat Modeling introduces severe systemic risk, violating the core tenets of defense-in-depth and least privilege.

## 2. Symptoms & Consequences
- Unidentified architectural vulnerabilities

## 3. Root Cause
- Architectural shortcuts, unmanaged technical debt, or lack of automated preventative guardrails.

## 4. Architectural Refactoring
- **Remediation**: Mandatory STRIDE review at ARB
