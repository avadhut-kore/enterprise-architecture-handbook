# Security Anti-Pattern: Compliance Checkbox Architecture

## 1. Description & Context
Compliance Checkbox Architecture introduces severe systemic risk, violating the core tenets of defense-in-depth and least privilege.

## 2. Symptoms & Consequences
- Passing audits without real security

## 3. Root Cause
- Architectural shortcuts, unmanaged technical debt, or lack of automated preventative guardrails.

## 4. Architectural Refactoring
- **Remediation**: Threat-model driven engineering controls
