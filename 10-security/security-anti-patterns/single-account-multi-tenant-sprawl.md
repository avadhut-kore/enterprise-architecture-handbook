# Security Anti-Pattern: Single-Account Multi-Tenant Sprawl

## 1. Description & Context
Single-Account Multi-Tenant Sprawl introduces severe systemic risk, violating the core tenets of defense-in-depth and least privilege.

## 2. Symptoms & Consequences
- Blast radius across all environments

## 3. Root Cause
- Architectural shortcuts, unmanaged technical debt, or lack of automated preventative guardrails.

## 4. Architectural Refactoring
- **Remediation**: Multi-account landing zone partitioning
