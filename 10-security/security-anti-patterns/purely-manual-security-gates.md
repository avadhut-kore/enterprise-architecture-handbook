# Security Anti-Pattern: Purely Manual Security Gates

## 1. Description & Context
Purely Manual Security Gates introduces severe systemic risk, violating the core tenets of defense-in-depth and least privilege.

## 2. Symptoms & Consequences
- Security review bottleneck

## 3. Root Cause
- Architectural shortcuts, unmanaged technical debt, or lack of automated preventative guardrails.

## 4. Architectural Refactoring
- **Remediation**: Automated DevSecOps pipeline gates
