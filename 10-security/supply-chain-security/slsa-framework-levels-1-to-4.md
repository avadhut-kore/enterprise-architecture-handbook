# SLSA Framework (Levels 1 to 4) & Build Provenance

## Executive Summary

Supply-chain Levels for Software Artifacts (SLSA) establishes four levels of build integrity:
- **SLSA 1**: Scripted build with available provenance metadata.
- **SLSA 2**: Build executed on a hosted build service (GitHub Actions); signed provenance generated by the service.
- **SLSA 3**: **Hermetic & Isolated Builds**. The build environment is ephemeral, isolated from external network access, and prevents build scripts from tampering with the generated provenance.
