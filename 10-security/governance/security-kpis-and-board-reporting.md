# Security KPIs & Executive Board Reporting

## Executive Summary

| Security KPI | Target Threshold | Business Meaning |
| :--- | :--- | :--- |
| **Mean Time to Detect (MTTD)** | $< 15\text{ minutes}$ | How rapidly the organization discovers an unauthorized intrusion. |
| **Mean Time to Remediate (MTTR)**| $< 60\text{ minutes}$ | How rapidly the organization contains and neutralizes active threats. |
| **Patch SLA Compliance** | $\ge 98\%$ | Percentage of vulnerabilities remediated within policy SLAs. |
| **Phishing Susceptibility** | $< 2\%$ | Percentage of employees clicking simulated phishing links. |
| **Unapproved Cloud Sprawl** | $0$ | Number of shadow IT cloud accounts operating outside landing zone guardrails. |
