# Internal Developer Platforms: Architecture & Backstage

## Executive Summary

An Internal Developer Platform (IDP) treats the developer experience as a product. The core interface is typically an open-source framework like **Spotify Backstage**.

---

## 1. The Core Pillars of an IDP

1. **Central Software Catalog**: A single authoritative directory of every microservice, API, library, and data pipeline running across the enterprise, including ownership and on-call rotations.
2. **Software Templates (Scaffolding)**: One-click creation of new, production-ready microservices adhering to enterprise standards.
3. **Software Scorecards**: Real-time gamified grading of service maturity (e.g., Bronze, Silver, Gold) based on test coverage, vulnerability remediation, and SLO definitions.
