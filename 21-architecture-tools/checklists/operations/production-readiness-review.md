# Checklist: Production Readiness Review (PRR) Checklist

## Executive Summary
This operational checklist must be validated prior to production promotion.

---

## Verification Criteria
- [ ] Architecture deployed across 3 Availability Zones.
- [ ] STRIDE threat model ratified by ARB.
- [ ] Golden Signals dashboard live in Grafana.
- [ ] Multi-window SLO burn-rate alerts active in PagerDuty.
- [ ] Verified operational runbooks published for all alerts.
- [ ] Progressive canary deployment pipeline active.
