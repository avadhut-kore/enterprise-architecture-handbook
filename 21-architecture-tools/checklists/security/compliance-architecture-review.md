# Checklist: Compliance Architecture Review Checklist

## Executive Summary
This checklist establishes the required technical and architectural controls evaluated during formal governance reviews.

---

## Verification Criteria
- [ ] PCI-DSS CDE scope minimized via Tokenization Proxy.
- [ ] GDPR Right to be Forgotten automated via cryptographic shredding.
- [ ] HIPAA ePHI protected via end-to-end TLS 1.3 and KMS encryption.
- [ ] SOC 2 Type II audit evidence gathered automatically via APIs.
- [ ] Data residency boundaries enforced via cloud regional constraints.
