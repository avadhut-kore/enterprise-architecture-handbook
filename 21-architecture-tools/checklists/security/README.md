# Enterprise Security Checklists (`checklists/security/`)

## Executive Summary

These checklists provide formal verification gates used by the Architecture Review Board (ARB), CISO teams, and engineering leads to evaluate security readiness before deployment.

---

## Security Checklists Index
- [`security-architecture-review.md`](security-architecture-review.md) - High-level architectural security gate review.
- [`threat-model-review.md`](threat-model-review.md) - STRIDE threat model verification gate.
- [`application-security-review.md`](application-security-review.md) - OWASP Top 10 and code-level security checklist.
- [`api-security-review.md`](api-security-review.md) - API gateway, rate limiting, and token verification checklist.
- [`identity-review.md`](identity-review.md) - IAM, least privilege, SCIM, and Workload Identity checklist.
- [`cloud-security-review.md`](cloud-security-review.md) - Multi-account landing zone, VPC, and CSPM checklist.
- [`data-security-review.md`](data-security-review.md) - Envelope encryption, KMS, and tokenization checklist.
- [`devsecops-review.md`](devsecops-review.md) - CI/CD automated gates, SAST, SCA, and image signing checklist.
- [`kubernetes-security-review.md`](kubernetes-security-review.md) - Pod Security Standards (`restricted`) and eBPF checklist.
- [`compliance-architecture-review.md`](compliance-architecture-review.md) - GDPR, PCI-DSS, and SOC 2 readiness checklist.
