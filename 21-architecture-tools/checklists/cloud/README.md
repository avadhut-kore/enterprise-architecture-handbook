# Cloud Architecture Checklists (`21-architecture-tools/checklists/cloud/`)

## Overview

This directory provides structured assessment checklists for evaluating cloud infrastructure, landing zones, migrations, disaster recovery topologies, and security boundaries.

---

## Index of Cloud Checklists

| Checklist | Focus Area | Target Audience |
| :--- | :--- | :--- |
| [`cloud-architecture-review.md`](cloud-architecture-review.md) | ARB governance gate, Multi-AZ resilience, static stability, decoupled compute | Architecture Review Board, Enterprise Architects |
| [`cloud-landing-zone-checklist.md`](cloud-landing-zone-checklist.md) | Multi-account structure, preventative guardrails (SCPs), transit networking | Cloud Platform Engineers, Security Architects |
| [`cloud-migration-readiness-checklist.md`](cloud-migration-readiness-checklist.md) | Wave planning, discovery, CDC replication lag, reverse-replication rollback | Migration Factory Lead, Solution Architects |
| [`cloud-disaster-recovery-checklist.md`](cloud-disaster-recovery-checklist.md) | RTO/RPO alignment, cross-region replication, IaC secondary automation, game days | Reliability Engineers, Enterprise Architects |
| [`cloud-security-guardrails-checklist.md`](cloud-security-guardrails-checklist.md) | Workload identity federation, Kubernetes PSS, CSPM, WORM compliance logs | CISO Team, Cloud Security Architects |
