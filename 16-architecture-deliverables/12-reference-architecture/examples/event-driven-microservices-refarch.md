## 1. Summary
Establishes the enterprise baseline for building event-driven microservices on AWS EKS and Apache Kafka. Mandates Clean Architecture domain layering, Transactional Outbox pattern for publishing, CloudEvents 1.0 JSON payloads, and OpenTelemetry distributed tracing across all asynchronous event hops.
