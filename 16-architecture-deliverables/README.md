# Architecture Deliverables & Templates

This directory provides the enterprise-grade deliverables kit and templates for architecture documentation, decision records, high-level designs, and risk registers.

## Deliverable Templates

- [ADR Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/ADR-TEMPLATE.md) — Architecture Decision Record standard format.
- [Solution Architecture Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/SOLUTION-ARCHITECTURE-TEMPLATE.md) — End-to-end solution blueprint standard.
- [System Design Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/SYSTEM-DESIGN-TEMPLATE.md) — Distributed system design document.
- [HLD Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/HLD-TEMPLATE.md) — High-Level Design document.
- [LLD Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/LLD-TEMPLATE.md) — Low-Level Design document.
- [Security Design Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/SECURITY-DESIGN-TEMPLATE.md) — Threat model & security design.
- [Data Design Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/DATA-DESIGN-TEMPLATE.md) — Data schema & storage design.
- [Integration Design Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/INTEGRATION-DESIGN-TEMPLATE.md) — API & event messaging design.
- [Risk Register Template](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/RISK-REGISTER-TEMPLATE.md) — Architectural risk tracking.

## Subdirectories

- [adr/](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/adr/README.md) — Master catalog of enterprise ADRs (ADR-0001 through ADR-0115).
- [architecture-review/](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/architecture-review/README.md) — Architecture review packages.
- [risk-register/](file:///d:/company/products/enterprise-architecture-handbook/16-architecture-deliverables/risk-register/README.md) — Domain risk registers.
