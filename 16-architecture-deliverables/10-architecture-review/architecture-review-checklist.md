# ARB Master Evaluation Checklist
- [ ] Strategic Alignment: Conforms to enterprise standards and cloud roadmap.
- [ ] Requirements Traceability: NFRs are quantified and testable.
- [ ] Security & Privacy: Threat model signed off; Zero Trust principles enforced.
- [ ] Failure Resilience: Chaos modes, timeouts, and multi-AZ redundancy accounted for.
- [ ] Cost / FinOps: TCO calculated and within allocated budget envelope.
